# マキナツ いきもの音楽室

公開ページは、リポジトリ直下の `music.html` です。既存のURLを引き継いでいます。
CSS・JavaScript・軽量サムネイルをこのフォルダーに分け、カタログやゲームのファイルと独立させています。

## 新しい曲を追加する

1. MP3音声をリポジトリ直下に置きます。
2. サムネイルを `music-room/images/` に置きます。
3. `music-room/songs.js` の `songs` に曲を1件追加します。
   - `id`: ほかの曲と重複しないID
   - `order`: 現在の最大値より1大きい番号（追加順）
   - `title`: 表示する曲名
   - `category`: `sea`、`insect`、`land`、`makinatsu` のいずれか
   - `keywords`: 生き物の別名や、ひらがなでの検索語
   - `audio` / `image`: 音声・サムネイルのファイル名
   - `duration`: 曲の長さ（秒・整数）

一覧、検索結果、カテゴリー件数、再生順は曲データから作られます。
「いちばん新しい歌」のラベルは、`order` が最大の曲へ自動で移ります。
音声や画像のアップロードだけでは曲一覧には追加されません。

## 再生

ひとつの音声プレーヤーで再生し、曲同士が同時に鳴ることを防ぎます。
検索や並び替えをしても現在の再生を続けます。曲を選んだときの一覧を再生順として保持します。
1曲リピートは曲ごとにオン・オフを保持します。
リピートがオフの場合は曲末で次の曲へ進み、最後の曲から先頭に戻ります。
一覧が1曲だけの場合は、リピートがオフなら曲末で停止します。
